## 🎓 TECHNICAL IMPLEMENTATION

### JavaScript Architecture
```javascript
┌─ STATE MANAGEMENT ───────────────────────────────┐
│  • frames[]        → Preloaded image array        │
│  • currentFrame    → Active frame index           │
│  • isLoading       → Loading state flag           │
│  • scrollTicking   → Scroll throttle flag         │
└──────────────────────────────────────────────────┘

┌─ PARTICLE SYSTEM ────────────────────────────────┐
│  • Particle class  → x, y, vx, vy, radius, hue   │
│  • 50 instances    → Animated particles           │
│  • update()        → Position calculation         │
│  • draw()          → Canvas rendering             │
│  • connections     → Line drawing between near    │
└──────────────────────────────────────────────────┘

┌─ SCROLL SYSTEM ──────────────────────────────────┐
│  • handleScroll()  → Throttled event handler     │
│  • updateVideoFrame() → Frame index calculation  │
│  • drawFrame()     → Canvas rendering             │
│  • revealCards()   → Intersection detection       │
└──────────────────────────────────────────────────┘
```
